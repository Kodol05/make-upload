## 상태 기호

- `○`: 완료 및 검수
- `△`: 초안 또는 생성 결과만 존재

## 품목별 전달 묶음

한 품목을 앱에 전달할 때 다음 파일과 정보가 모두 있어야 한다.

```text
itemId
├─ 검수된 한국어 이름·요약·단계·흔한 실수
├─ 공식 출처 ID와 실제 URL
├─ needsLocalCheck와 이유
├─ 영어·중국어·베트남어 검수본
└─ public/images/items/<itemId>/
   ├─ 01.webp
   ├─ 02.webp
   ├─ 03.webp
   └─ 04.webp  # 실제 처리 단계가 네 개일 때만 사용
```

단계 이미지에는 글자를 넣지 않는다. 네 언어 설명과 대체 텍스트는 `shared/catalog.ts`에서 관리한다.

## 스캔 발표 샘플

개인정보와 브랜드 로고가 없는 직접 촬영 또는 사용권이 확보된 사진만 사용한다.

| 용도 | 구성 | 상태 |
| --- | --- | --- |
| 단일 품목 1~5 | 대표 품목 한 개씩 | × |
| 다중 품목 1 | 투명 페트병 + 캔 | × |
| 다중 품목 2 | 종이상자 + 배달용기 | × |
| 모호한 사진 | 재질 판단이 어려운 용기 | × |

고정 발표 사진은 마지막 리허설 3회에서 연속 성공한 파일만 채택한다.
