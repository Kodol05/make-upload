## 상태 기호

- `○`: 완료 및 검수
- `△`: 초안 또는 생성 결과만 존재
- `×`: 아직 시작하지 않음

현재는 개발 착수 전이므로 모든 제작 항목을 `×`로 기록한다. 작업자가 완료 시 기호와 관련 파일·출처를 함께 갱신한다.

## 품목별 전달 묶음

한 품목을 앱에 전달할 때 다음 파일과 정보가 모두 있어야 한다.

```text
itemId
├─ 검수된 한국어 이름·요약·단계·흔한 실수
├─ 공식 출처 ID와 실제 URL
├─ needsLocalCheck와 이유
├─ 영어·중국어·베트남어 검수본
└─ public/images/items/<itemId>/
   ├─ 01.webp
   ├─ 02.webp
   ├─ 03.webp
   └─ 04.webp  # 실제 처리 단계가 네 개일 때만 사용
```

단계 이미지에는 글자를 넣지 않는다. 네 언어 설명과 대체 텍스트는 `shared/catalog.ts`에서 관리한다.

## UI 문자열

도감 16종·FAQ 20개와 **별개로** 화면 자체의 문자열도 네 언어가 필요하다. 메뉴 이름, 버튼,
안내 문구, 오류 메시지, 게임 UI 등을 합쳐 60~100개로 추정한다.

전부 `src/i18n/strings.ts` 한 파일에 모여 있으므로 이 파일만 열면 된다. 한국어가 이미
채워진 항목에 나머지 세 언어를 더하는 방식이고, 아직 안 채운 자리는
`__TODO__:ui.nav.learn.en` 형태로 표시되어 있어 눈으로 찾을 수 있다.

```powershell
git grep -n "__TODO__" -- src/i18n
```
