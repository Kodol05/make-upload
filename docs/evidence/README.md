각 파일을 추가할 때 [보고서·PPT 인수인계](../REPORT_AND_PPT_HANDOFF.md)의 검증 기록표에 날짜, 결과, 관련 커밋을 함께 기록한다.

커밋 전 확인:

- API 키, token, 이메일, 브라우저 개인 정보가 보이지 않는다.
- 사용자 업로드 사진에 얼굴, 이름, 주소 등 개인정보가 없다.
- 구현되지 않은 기능을 실제 동작 화면처럼 꾸민 이미지를 사용하지 않는다.
- 화면 해상도와 파일 용량을 보고서·PPT에 적합하게 최적화한다.
