# fal.ai ElevenLabs TTS 디렉션

## 모델과 보이스

- 엔드포인트: `fal-ai/elevenlabs/tts/multilingual-v2`
- 공식 문서: <https://fal.ai/models/fal-ai/elevenlabs/tts/multilingual-v2/api>
- 1차 보이스: `River` — 성별 인상이 과도하게 강하지 않은 차분한 교육 톤을 목표로 함
- 2차 보이스: `Rachel` — `River`가 계정 또는 현재 모델에서 제공되지 않을 때 사용할 공식 기본값
- 언어 강제: `language_code: "ko"`
- 속도: `0.95`; 음질 저하를 피하기 위해 허용 범위 0.7~1.2의 중앙에 가깝게 유지

실제 호출 전 두 보이스로 S03 한 문장만 미리 듣고, 한국어 억양과 `헹구고`, `조개껍데기`, `종량제` 발음을 기준으로 하나를 고른다. 이 미리 듣기는 유료 호출 단계에 포함되므로 현재는 실행하지 않는다.

## 장면별 생성 이유

전체 원고를 한 번에 생성하지 않고 14개 장면별로 요청한다.

- 각 문장이 정확한 영상 구간 안에 들어간다.
- 한 문장만 발음이 틀려도 해당 장면만 다시 생성한다.
- `previous_text`와 `next_text`로 장면 사이 억양 연결을 유지한다.
- `timestamps: true`로 단어별 타임스탬프를 받아 자막 미세 조정에 사용한다.

## 발음 사전

| 화면 표기 | TTS 입력 | 목표 발음 |
| --- | --- | --- |
| K-SORT | 케이 소트 | `케이-소트`, 두 단어 사이 짧은 연결 |
| RFID | 알 에프 아이 디 | 영문자를 한국어로 하나씩 읽음 |
| 무색 페트병 | 무색 페트병 | `무색`과 `페트병` 사이 자연스러운 띄어 읽기 |
| 조개껍데기 | 조개껍데기 | `껍떼기`처럼 된소리가 지나치지 않게 |
| 종량제봉투 | 종량제봉투 | `종냥제`의 자연스러운 한국어 연음 허용 |

## 연기 방향

- 목소리는 웃지 않은 친절함, 강의보다 옆에서 설명하는 느낌.
- S01은 공감, S02는 낮고 또렷한 주의, S03~S12는 실행 지시, S13~S14는 밝은 해결.
- 문장 끝을 습관적으로 올리지 않고 평서문은 안정적으로 내린다.
- `비우고, 헹구고, 분리하고, 섞지 않습니다`는 네 동사를 같은 박자로 읽는다.
- S12는 건전지·형광등·소형가전 사이에 짧은 쉼을 둔다.
- 과장된 감정, 광고식 미소, 속삭임, 뉴스 앵커 톤을 피한다.

## 출력과 후처리

- 원본: `pcm_48000`, 모노 유지, 파일명 `public/media/audio/vo-S01.wav`부터 `vo-S14.wav`
- 장면별 앞 무음 80~150ms, 뒤 무음 250~500ms 확보
- 클릭·팝 제거용 5ms 페이드 인·아웃
- 최종 음성 버스: 약 `-16 LUFS`, true peak `-3 dBTP` 이하
- 문장이 목표 구간보다 길면 먼저 `speed`를 최대 `1.02`까지만 올리고, 그래도 길면 문장 사이 무음을 줄인다.

## 호출 예시

아래 예시는 검토용이며 실행하지 않는다. 인증값은 환경변수에서만 읽는다.

```js
import { fal } from "@fal-ai/client";

fal.config({ credentials: process.env.FAL_KEY });

const result = await fal.subscribe(
  "fal-ai/elevenlabs/tts/multilingual-v2",
  { input: { ...sharedInput, ...sceneRequest } },
);
```
