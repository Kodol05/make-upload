# K-SORT 오디오 믹싱 큐시트

## 버스 우선순위

1. 한국어 내레이션
2. 의미를 전달하는 짧은 효과음
3. Suno 배경음악
4. 공간 앰비언스

## 레벨 목표

- 내레이션 통합 음량: 약 `-16 LUFS`, true peak `-3 dBTP` 이하
- BGM 단독 구간: 약 `-24`~`-20 LUFS` 체감, 음성 구간에서 사이드체인 또는 오토메이션으로 3~5dB 낮춤
- 효과음 피크: 보통 `-12`~-9 dBFS, 성공 차임도 음성보다 작게
- 최종 프로그램: 웹 재생 기준 약 `-14`~-16 LUFS`, true peak `-1 dBTP` 이하
- 리미터로 음량을 밀기 전에 음성 명료도와 자막 타이밍을 우선한다.
