# K-SORT 2분 한국어 내레이션

## 최종 낭독본

한국에서 생활하다 보면, 쓰레기통 앞에서 한 번쯤 망설이게 됩니다.

잘못 섞인 쓰레기는 재활용을 어렵게 하고, 건전지는 화재 위험도 높입니다.

기억할 것은 네 가지. 비우고, 헹구고, 분리하고, 섞지 않습니다.

첫째, 용기 속 남은 내용물을 완전히 비웁니다.

둘째, 음식물과 이물질을 물로 깨끗이 헹굽니다.

셋째, 라벨과 뚜껑처럼 다른 재질은 떼어 냅니다.

넷째, 종류가 다른 재활용품은 서로 섞지 않습니다.

무색 페트병은 라벨과 내용물을 제거하고 헹군 뒤, 압착해 뚜껑을 닫아 배출합니다.

배달용기처럼 오염된 플라스틱은 깨끗이 씻습니다. 지워지지 않으면 재활용품에 섞지 마세요.

음식물쓰레기는 수분과 이물질을 줄이고, 지역의 전용봉투나 알 에프 아이 디 수거함을 이용합니다.

하지만 닭뼈와 조개껍데기는 음식물이 아닙니다. 일반 종량제봉투로 배출합니다.

폐건전지는 전지 수거함에, 깨지지 않은 형광등은 형광등 수거함에, 소형가전은 지정 수거 지점에 배출합니다.

이렇게 깨끗하게 분리하면 재활용품은 다시 자원으로 쓰일 가능성이 높아집니다.

세부 방법은 지역마다 다를 수 있습니다. 케이 소트로 확인하고, 오늘부터 정확하게 실천해 보세요.

## TTS 편집 원칙

- 각 샷별로 별도 생성한 뒤 120초 타임라인에 배치하면 재생 속도를 억지로 바꾸지 않아도 된다.
- 문장 끝 침묵은 0.25~0.5초, S12의 열거 사이에는 0.15~0.25초를 둔다.
- 최종 합성본의 내레이션 피크는 약 `-3 dBFS`, 통합 음량 목표는 약 `-16 LUFS`로 잡는다.
- 너무 느린 결과는 무음만 줄이고, 음성 자체의 시간 압축은 3%를 넘기지 않는다.
