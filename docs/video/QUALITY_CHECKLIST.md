# K-SORT 영상 프리프로덕션 품질 체크리스트

## A. 캐릭터 시트

- [x] 미나의 정면, 좌측면, 후면, 3/4 시점에서 얼굴과 체형이 같은 인물이다.
- [x] 틸색 헤어클립이 채택 시트의 정면 화면 기준 왼쪽 앞머리에 있다.
- [x] 크림 후드티, 숲색 재킷, 네이비 바지, 흰 운동화가 모든 자세에서 유지된다.
- [x] 정면 중립, 망설임, 집중, 절제된 미소가 서로 구분된다.
- [x] 손 자세는 펼친 손, 병 잡기, 라벨 잡기, 수거함에 놓기로 제한된다.
- [x] 글자, 로고, 국기, 학교 문장, 워터마크가 없다.

## B. 배경 시트

- [x] 네 공간이 웜 아이보리·우드·틸·블루 팔레트와 오전광을 공유한다.
- [x] 수거함의 용도는 물리적 형태로 구분되지만 생성형 글자는 없다.
- [x] 인물과 손이 없으며 공간 구조를 가리는 큰 소품이 없다.
- [x] 바닥이 건조하고 통로가 안전하며 깨진 유리·형광등이 없다.
- [x] 카메라 원근이 35mm 상당으로 과장되지 않았다.

## C. 스토리보드

- [x] 1번부터 14번 샷까지 빠짐없이 대응된다.
- [x] 각 패널의 주 행동은 한 가지뿐이다.
- [x] 행동 순서가 `망설임 → 이해 → 행동 → 비교 → 함께 실천`으로 읽힌다.
- [x] 화면 이동 방향이 기본적으로 왼쪽에서 오른쪽이다.
- [x] 손 클로즈업에서는 불필요한 얼굴과 다른 손이 프레임에 없다.
- [x] 패널 내부에는 생성형 글자가 없고 번호·설명은 문서에만 있다.

## D. 사실과 안전

- [x] 무색 페트병은 라벨·내용물 제거, 헹굼, 압착, 뚜껑 닫기의 흐름과 충돌하지 않는다.
- [x] 음식물은 수분과 이물질을 줄인 뒤 지역 전용 방식으로 배출한다고 설명한다.
- [x] 닭뼈와 조개껍데기는 일반 종량제폐기물로 표현한다.
- [x] 건전지는 다른 재활용품과 섞지 않고 전지 수거함에 넣는다.
- [x] 형광등은 깨지지 않은 상태로 안전하게 운반한다.
- [x] 지역에 따라 세부 방식이 달라질 수 있다는 안내가 포함된다.
- [x] 출처 없는 통계, 법적 단정, 특정 지자체에만 맞는 봉투 색을 사용하지 않는다.

## E. 타이밍과 오디오

- [x] 14개 샷의 합계가 정확히 120초다.
- [x] 각 내레이션 문장이 해당 자막 큐 안에서 2.9~4.7자/초 범위로 배치된다.
- [ ] 내레이션은 행동보다 0.2~0.4초 먼저 핵심 동사를 제시한다.
- [ ] BGM은 무보컬이며 음성보다 앞에 나오지 않는다.
- [ ] 효과음은 물 붓기, 헹굼, 라벨 벗김, 내려놓기, 성공 차임만 사용한다.

## F. 생성 프롬프트

- [x] 각 샷에 시작 프레임, 주 행동, 카메라, 종료 프레임이 있다.
- [x] 한 샷에 카메라 동작이 하나뿐이다.
- [x] 추가 인물, 오브젝트 복제, 손 왜곡, 글자 생성 방지 문구가 포함된다.
- [x] 생성 실패 시 전체 샷이 아니라 해당 샷만 재생성하도록 매핑되어 있다.
- [x] 고위험 클립 S06과 S12b만 두 번째 후보 생성을 허용한다.

## G. 보안과 실행 경계

- [x] 문서와 JSON에 실제 API 키가 없다.
- [x] fal.ai 인증은 실행 시 `FAL_KEY` 환경변수로만 읽는다.
- [x] 이번 작업에서 Seedance, ElevenLabs, Suno 유료 호출을 실행하지 않았다.
- [ ] 실제 호출 전 노출된 fal.ai 키가 폐기되고 새 키로 교체되었는지 확인한다.
- [x] 생성 명령은 검토용으로만 기록되어 있으며 자동 실행되지 않는다.

## 최종 상태

- 프리프로덕션 패키지: `생성 준비 완료`
- 다음 외부 작업: 회전된 키 설정 → 정지 이미지 승인 → Seedance 샷 1부터 순차 생성
