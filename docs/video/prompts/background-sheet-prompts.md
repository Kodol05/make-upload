# 배경 시트 생성 프롬프트

## 공통 기준

각 이미지는 인물이 없는 16:9 환경 설정화다. 네 공간 모두 웜 아이보리, 연한 우드, 딥 틸과 클린 블루 포인트, 부드러운 오전 자연광을 공유한다. 생성된 구조물 표면에는 글자와 픽토그램을 넣지 않는다.
