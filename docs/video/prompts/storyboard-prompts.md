# 스토리보드 시트 생성 프롬프트

## 참조 순서

각 호출에는 다음 프로젝트 파일을 필요한 만큼 첨부한다.

1. `character-sheet-mina.png` — 미나의 얼굴·의상·색상 기준
2. `character-sheet-supporting-cast.png` — 마지막 단체 샷 기준
3. `background-dorm-kitchen.png` — S01, S03~S11 공간 기준
4. `background-recycling-station.png` — S02, S13 공간 기준
5. `background-special-collection.png` — S12 공간 기준
6. `background-campus-hub.png` — S14 공간 기준

시트 내부에는 패널 번호나 설명을 생성하지 않는다. 패널 순서는 왼쪽에서 오른쪽, 위에서 아래이며 정확한 번호와 설명은 `STORYBOARD.md`에서 관리한다.
