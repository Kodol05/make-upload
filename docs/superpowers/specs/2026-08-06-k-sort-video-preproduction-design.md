# K-SORT 2분 교육 영상 프리프로덕션 설계

## 1. 목표와 완료 경계

K-SORT의 핵심 사용자인 한국 거주 외국인 대학생이 2분 안에 분리배출의 필요성과 핵심 행동을 이해하도록 한다. 이번 작업은 Seedance 유료 영상 생성 직전까지 완료한다.

완료 산출물은 다음과 같다.

- 고정된 주인공과 보조 출연자의 캐릭터 시트
- 기숙사 주방, 캠퍼스 분리배출장, 특수폐기물 수거 지점의 배경 시트
- 120초, 14개 샷의 스토리보드와 편집 타임라인
- 한국어 내레이션 원고와 WebVTT 자막
- fal.ai ElevenLabs TTS 실행 명세
- Suno 배경음악 프롬프트와 믹싱 큐시트
- Seedance 1.5 Pro용 장면별 이미지투비디오 프롬프트와 생성 매니페스트
- 생성 전 품질·안전·사실 검수 체크리스트

실제 Seedance 호출, ElevenLabs 유료 호출, Suno 생성과 최종 영상 편집은 이번 범위에서 제외한다. 대화에 노출된 fal.ai 키는 사용하거나 파일에 기록하지 않는다.

## 2. 참고 영상에서 채택한 제작법

참고 영상 `https://www.youtube.com/watch?v=y7eVSK2ODVE`의 공개 자동자막을 분석해 다음 방식을 채택한다.

1. 시놉시스를 장면 목록으로 먼저 분해한다.
2. 영상보다 캐릭터와 세계관을 먼저 확정한다.
3. 캐릭터 시트와 배경 시트를 모든 후속 이미지의 참조로 사용한다.
4. 완성 영상을 예측할 수 있도록 스토리보드를 먼저 만든다.
5. 한 샷에는 하나의 주 행동만 넣고 짧은 클립으로 생성한다.
6. AI가 작성한 장문 프롬프트를 사람이 읽고 충돌과 불필요한 동작을 제거한다.
7. 도입의 공간 제시, 액션 전 클로즈업, 화면 이동 방향의 연속성을 편집에서 유지한다.

## 3. 비주얼 접근 결정

검토한 접근은 세 가지다.

| 접근 | 장점 | 위험 | 결정 |
| --- | --- | --- | --- |
| 실사형 공익광고 | 현실감과 즉시성이 높음 | 얼굴·손·의상 일관성 비용이 큼 | 제외 |
| 스타일라이즈드 3D | 행동이 명확하고 참조 시트 일관성이 좋음 | 지나치게 귀여우면 정보 신뢰도가 낮아질 수 있음 | 채택 |
| 플랫 2D 인포그래픽 | 가장 안정적이고 저렴함 | 공간감과 영상적 몰입이 약함 | 예비 대안 |

최종 아트 방향은 친근하지만 유아적이지 않은 스타일라이즈드 3D 공익교육 애니메이션이다. 재질은 현실적으로 보이되 인물의 비율과 표정은 살짝 단순화한다.

## 4. 비주얼 바이블

### 색과 조명

- 기능색: 딥 틸 `#0F766E`, 클린 블루 `#2563EB`
- 배경색: 웜 아이보리 `#F7F5EF`, 소프트 그레이 `#E5E7EB`
- 경고색: 앰버 `#F59E0B`; 오류 표현에만 제한적으로 사용
- 자연광 중심의 부드러운 오전 조명, 약한 접촉 그림자, 과한 네온과 극적 명암 금지

### 형태와 재질

- 둥글고 읽기 쉬운 실루엣, 현실적인 일상 쓰레기 크기
- 투명 페트병, 금속 캔, 종이, 음식물, 건전지와 형광등의 재질 차이가 즉시 보여야 함
- 생성 이미지 안에는 글자, 숫자, 브랜드, 학교 로고, 워터마크를 넣지 않음
- 분리배출함은 색과 형태로만 구분하고 실제 라벨은 편집 단계에서 추가

### 카메라

- 16:9, 1280×720 최종 납품, 원본 시트는 고해상도
- 인물 기준 35mm 상당의 미디엄·와이드, 행동 기준 50mm 상당의 클로즈업
- 카메라 높이는 눈높이 또는 손높이, 과한 광각과 핸드헬드 금지
- 한 샷에 줌·팬·회전을 중복하지 않고 한 가지 움직임만 사용

## 5. 캐릭터 설계

### 주인공 미나

- 22세 국제학생, 따뜻한 중간 피부 톤, 짙은 갈색 턱선 길이 보브컷
- 왼쪽 앞머리의 작은 틸색 헤어클립이 핵심 식별자
- 크림색 후드티, 숲색 짧은 재킷, 네이비 스트레이트 팬츠, 흰 스니커즈
- 틸색 재사용 장바구니를 소품으로 사용
- 성격은 성실하고 호기심 많으며, 초반의 망설임이 후반의 자신감으로 바뀜
- 과장된 놀람, 입 모양 대사, 정면 립싱크는 사용하지 않음

### 보조 출연자

- 서로 다른 피부 톤과 헤어스타일을 가진 대학생 세 명
- 코랄, 머스터드, 블루 계열의 단색 캐주얼 의상
- 문화적 고정관념을 드러내는 국기, 전통복, 과장된 외형 사용 금지
- 마지막 샷에서만 등장해 공동 행동과 캠퍼스 확산을 보여 줌

### 일관성 기준

- 미나의 헤어클립 위치, 보브 길이, 재킷 색, 바지와 신발 형태를 모든 샷에서 유지
- 손가락 수와 물체 접촉을 확인하고, 손 클로즈업에서는 얼굴을 프레임 밖으로 둠
- 보조 출연자는 주인공의 의상 색과 겹치지 않게 함

## 6. 배경 설계

1. **기숙사 주방·준비대:** 밝은 싱크대, 우드 조리대, 틸색 소품, 음식물과 포장재를 씻고 분리하는 공간
2. **캠퍼스 분리배출장:** 반실내형 수거 공간, 흰색 벽과 우드 슬랫, 색으로 구분한 수거함, 깨끗한 바닥
3. **특수폐기물 수거 지점:** 도서관 또는 학생회관 복도 한쪽, 건전지·형광등·소형가전용 형태가 다른 수거함
4. **엔딩 캠퍼스 허브:** 녹지와 현대식 대학 건물이 보이는 밝은 공간, 여러 학생이 자연스럽게 이동

모든 공간은 같은 캠퍼스 세계로 보이도록 우드, 웜 화이트, 틸·블루 포인트와 오전 자연광을 반복한다.

## 7. 이야기와 120초 구조

이야기의 감정선은 `망설임 → 이해 → 직접 행동 → 자신감 → 함께 실천`이다.

| 구간 | 시간 | 기능 |
| --- | ---: | --- |
| 훅과 필요성 | 0–16초 | 섞이면 재활용이 어려워지고 안전 문제도 생길 수 있음을 제시 |
| 네 가지 원칙 | 16–52초 | 비우기, 헹구기, 분리하기, 섞지 않기를 행동으로 학습 |
| 대표 품목 | 52–90초 | 무색 페트병, 오염 용기, 음식물과 뼈·껍데기 구분 |
| 특수폐기물 | 90–102초 | 건전지, 형광등, 소형가전을 전용 지점으로 이동 |
| 비교와 결말 | 102–120초 | 잘못된 배출과 올바른 배출을 비교하고 K-SORT 사용으로 마무리 |

총 14개 샷이며 각 샷은 7~12초다. 생성 모델에는 화면 내 글자를 맡기지 않고 제목, 네 가지 원칙, 지역 확인 안내와 K-SORT 로고는 편집 오버레이로 처리한다.

## 8. 사실 기준

영상의 전국 공통 문장은 생활폐기물 분리배출 누리집의 공식 안내를 기준으로 한다.

- 무색 페트병: 라벨과 내용물을 제거하고 헹군 뒤 압착하고 뚜껑을 닫아 배출
- 음식물류폐기물: 수분과 이물질을 줄이고 지역의 전용봉투·납부필증·RFID 방식으로 배출
- 닭뼈와 조개껍데기: 일반 종량제폐기물로 배출
- 건전지: 다른 재활용품과 분리해 전지 수거함으로 배출
- 형광등: 깨지지 않은 상태로 형광등 수거함에 배출
- 지역별 방법이 다를 수 있으므로 거주지 지방자치단체 안내를 우선

공식 확인 URL은 `https://www.xn--oy2b29bd3a601b.kr/front/search/searchDispose.do`이다. 통계 수치는 출처와 시점이 화면에 복잡성을 더하므로 사용하지 않는다.

## 9. 오디오 설계

### 내레이션

- 한국어, 차분하고 친절한 20대 후반~30대 초반 느낌의 중성적 보이스
- 약 300~320자/분이 아니라 실제 낭독 기준 260~290음절/분 수준으로 여백을 둠
- 감정 강도는 낮음에서 중간, 지시 문장은 또렷하게, 공포·훈계조 금지
- 화면의 행동보다 0.2~0.4초 먼저 핵심 동사를 들려줌

### 배경음악

- 보컬 없는 100 BPM 전후의 에코 테크 공익광고 음악
- 마림바, 가벼운 플럭 신스, 소프트 퍼커션, 약한 어쿠스틱 기타
- 도입은 단순하게, 네 가지 원칙 구간에서 리듬을 더하고, 엔딩은 밝게 해결
- 내레이션 아래에서 약 `-24`~`-20 LUFS` 체감으로 유지하며 음성보다 앞에 나오지 않음

### 효과음

- 물 붓기, 짧은 헹굼, 라벨 벗김, 용기 놓기, 부드러운 성공 차임만 사용
- 유리 깨짐, 경보음, 과장된 충격음은 사용하지 않음

## 10. 모델과 비용 전략

- 이미지 시트와 스토리보드는 동일 참조 이미지 체계를 유지한다.
- 대부분의 영상 샷은 fal.ai Seedance 1.5 Pro 이미지투비디오, 720p, 무음으로 계획한다.
- Seedance 2.0은 엔딩 단체 샷이나 비교 샷이 1.5에서 반복 실패할 때만 후보로 둔다.
- 첫 생성은 샷당 한 개, 검수 통과 가능성이 낮은 손 동작 샷만 두 번째 후보를 허용한다.
- 샷마다 시작 프레임, 단일 행동, 카메라, 종료 프레임, 금지 요소를 명시한다.

## 11. 생성 전 승인 기준

- 14개 샷의 합계가 정확히 120초다.
- 내레이션이 장면별 목표 시간 안에 무리 없이 읽힌다.
- 모든 행동이 공식 안내와 충돌하지 않는다.
- 주인공의 식별자와 공간의 색·조명이 모든 시트에서 일치한다.
- 화면 안에 생성형 텍스트가 없다.
- 한 샷에 주 행동이 하나뿐이다.
- 손과 물체가 맞닿는 샷은 대체 컷 또는 편집용 정지 프레임을 갖는다.
- 유료 호출 파일에는 API 키가 없고 환경변수 이름만 있다.
