# 소감

## 김현민 — 웹앱·게임 개발

웹 쪽으로 아는 게 많은 편은 아니었다. 그래서 이번에는 AI와 대화하면서 필요한 것을 그때그때
배워 가며 썼다. 처음 보는 것은 물어보고, 왜 그렇게 되는지 듣고, 다시 고쳐 보는 식이었다.

디자인도 마찬가지였다. 한 번에 잘 나온 화면은 거의 없었다. AI와 주고받으며 조금씩 고쳐
나가는 동안 퀄리티가 올라갔다.

AI가 얼마나 발전했는지는 쓸 때마다 느끼지만, 직접 만들어 봐야 제대로 안다. 이번에도 그랬고
좋은 경험이 됐다.

앞으로 AI가 더 발전하더라도 계속 다룰 수 있으려면 나만의 활용법을 갖고 있어야 한다고
생각한다. 많이 써 보고, 무엇이 어떻게 바뀔지 스스로 판단하고, 빠르게 따라가야 하는 시대가
온 것 같다.
